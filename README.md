# ICLAB & Computer Architecture Projects

This repository contains my coursework and design exercises in **Digital IC Design** and **Computer Architecture**, focusing on RTL implementation, hardware architecture, and digital system design.

## 1. ICLAB – RTL Design

A collection of RTL design projects implemented using Verilog/SystemVerilog.

**Topics Covered:**
- Verilog/SystemVerilog RTL Design
- Finite State Machine (FSM) Design
- Pipeline Design
- RTL -> SYN -> GATE -> APR -> POST


## 2. CA – Computer Architecture

A collection of computer architecture studies, design exercises, and technical documentation.

**Topics Covered:**
- Cache Architecture and Design
- Processing Element (PE) Array Architecture
- Hardware Architecture Analysis
- Design Concepts and Implementation Studies

## Tools & Languages

- **ICLAB:** Verilog, SystemVerilog
- **CA:** C/C++

## Purpose

This repository serves as a collection of my academic work and practical experience in digital IC design and computer architecture, documenting my learning and development in hardware design.
